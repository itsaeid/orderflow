# گزارش آزمون — ۱۷ آبان ۱۴۰۵

## خودکار

اجرای `npm test`: ۳۵ مورد گزارش‌شده توسط Node test runner شامل ظرف آزمون API، بدون شکست.

- مسیر کامل ثبت سفارش تا تحویل.
- منع تأیید مالی قبل وصول پیش‌پرداخت.
- منع تکمیل تولید قبل پیشرفت صددرصد.
- برگشت QC با نقص، رفع ایراد و الزام تست و سریال.
- منع برگشت بدون توضیح.
- منع پرداخت بیش از مانده یا بدون مرجع.
- منع تأیید نهایی بدون تسویه و قرارداد.
- منع خروج بدون QC و تسویه.
- اصلاح نسخه سفارش برگشتی؛ منع اصلاح خاموش سند تأییدشده.
- رد نقش غیرمجاز و جلوگیری از جعل نقش در payload.
- مخفی‌کردن اسناد داخلی و سفارش سایر مشتریان.
- نشست HttpOnly و پاسخ 401 بدون ورود.
- رد درخواست نوشتن از origin غیرمجاز.
- idempotency درخواست تکراری.
- رد نسخه قدیمی و تست دو درخواست هم‌زمان: یکی موفق و دیگری 409.
- rollback تراکنش ناموفق بدون ثبت audit اضافی.
- ذخیره رویداد audit و outbox.
- بارگذاری سند مالی، نسخه سند و منع دانلود غیرمجاز.
- رد فایل دارای نوع PDF ولی محتوای نامعتبر.

API با NestJS واقعی روی HTTP و PGlite (PostgreSQL تعبیه‌شده) اجرا شد؛ این آزمون اثبات استقرار production PostgreSQL یا تست بار نیست.

## بررسی دستی مرورگر

- نمایش داشبورد فارسی و RTL در مرورگر بررسی شد.
- نقش QC فقط پرونده مرتبط را دید و مبلغ مالی نمایش داده نشد.
- برگشت بدون شرح نقص رد شد.
- برگشت با شرح نقص موفق بود و پرونده از کارتابل QC خارج شد.
- همان نقص در پنل تولید دیده شد.
- تولید با توضیح رفع ایراد دوباره به QC فرستاد.
- QC با گزارش تست و سریال تأیید کرد؛ پرونده به پیگیری تسویه رفت.
- سفارش جدید از فرم فروش ثبت و وارد تأیید فروش شد.
- پس از بازخوانی صفحه، سفارش جدید باقی ماند و با جستجو پیدا شد.
- پنل مشتری فقط دو سفارش متعلق به مشتری نمونه را نمایش داد.

## خطاهای پیدا و اصلاح‌شده

- عدم وجود crypto.randomUUID در HTTP پیش‌نمایش: جایگزین با crypto.getRandomValues.
- تداخل خروجی build و dev: خروجی توسعه به `.next-dev` تفکیک شد.
- حفظ شناسه کارشناس فروش در پاسخ مجاز برای اقدام روی پیش‌نویس برگشتی.
- نمایش مرحله ارسال مشتری بر پایه وضعیت واقعی به‌جای صرفاً درصد ساخت.

## محدودیت بررسی

تست مرورگر روی محیط دمو انجام شده است. دسترسی API در آزمون HTTP بررسی شد. استقرار سرور، مرورگر موبایل واقعی، تست بار، نفوذ تخصصی و بازیابی پشتیبان اجرا نشده‌اند.
